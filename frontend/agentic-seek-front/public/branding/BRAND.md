## 1. Brand Overview

### The Product
Save It Somewhere is a personal AI memory layer that captures screenshots and useful information, automatically extracts and understands the content, organizes it, and makes it searchable.

### The Promise
You save it somewhere. We make sure you find it.

### The Feeling
**RELIEF**

The user's primary emotional state should be: *"I don't have to remember. It does."*

The brand communicates reassurance, simplicity, trust, and the effortlessness of having their information safely organized.

## 2. Logo Concept

### Core Idea: "The Place"

The logo is an abstract mark that suggests something being safely "somewhere" without literally illustrating storage, databases, or AI technology.

### Visual Metaphor
A simple dot with subtle placement guides—like a marker on a map indicating that your information has a home. The guides are minimal and suggestive, not literal or technical.

### The Mark at a Glance
- **Center:** A circle representing the secure location
- **Guides:** Four minimal line segments (above, below, left, right) suggesting placement and discovery
- **Emotion:** Calm, reassuring, like a gentle hand placing something somewhere safe

### What It Is NOT
The logo deliberately avoids:
- Brain icons or neural networks
- Robot heads or AI imagery
- Magnifying glasses or search symbols
- Light bulbs or "idea" iconography
- Circuit boards or technical metaphors
- Database or storage folders
- Cloud icons or technical infrastructure

### Why This Works
1. **Distinctive:** The minimal placement guides are unique to this brand
2. **Memorable:** The mark is simple enough to recognize instantly
3. **Scalable:** Works perfectly from 16px favicon to 512px logo
4. **Trustworthy:** The calm, geometric form communicates reliability
5. **Human:** The simplicity suggests ease of use, not complexity

## 4. Clear Space & Minimum Size

### Clear Space
All logos require clear space around them—no elements should intrude into this zone.

**Clear Space Rule:** Equal to the height of the mark itself

For the icon alone: If the icon is 40px tall, maintain 40px clear space on all sides.

### Minimum Logo Size
- **Icon-only mark:** 16px × 16px (favicon size, acceptable minimum)
- **Primary logo (stacked):** 120px width minimum
- **Horizontal logo:** 200px width minimum
- **Wordmark:** 80px width minimum

Below these sizes, the logo loses legibility and should not be used.

### Accessibility Compliance

All color combinations meet **WCAG AAA** contrast standards:
- Dark Text (#1F1F1F) on Light Background (#FAFBF8): **15.1:1** contrast
- Light Text (#FAFBF8) on Dark Background (#0F0F0F): **14.8:1** contrast
- Primary Color (#2D6E6E) on Light Background: **5.4:1** contrast
- Primary Color on Dark Background: **3.2:1** contrast (acceptable for large text)

Do not use the primary color (#2D6E6E) for small body text on dark backgrounds.

## 6. Typography

### Typeface: System Sans-Serif Stack

**Font Stack (Recommended):**
```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Helvetica Neue', sans-serif;
```

This system stack provides:
- **Modern & Approachable:** Clean, contemporary feel
- **Highly Legible:** Optimized for screen reading
- **Accessible:** Great readability at all sizes
- **Performance:** System fonts load instantly

### Font Characteristics
- **Geometric but warm** — Not cold or futuristic
- **Contemporary** — Modern without being trendy
- **Humanist** — Friendly and approachable
- **Neutral** — Works across all contexts

### Font Weights in Use

**Headings (H1-H3):**
- **Weight:** 500 (Medium/Semibold)
- **Letter Spacing:** -0.5px to -0.8px
- **Usage:** Logo text, page titles, section headers

**Body Text:**
- **Weight:** 400 (Regular)
- **Letter Spacing:** Normal to +0.3px
- **Usage:** Content, descriptions, body copy

**Labels & UI:**
- **Weight:** 500 (Medium)
- **Letter Spacing:** Normal to +0.5px
- **Usage:** Button labels, form labels, navigation

**Small Text (UI, metadata):**
- **Weight:** 400 (Regular)
- **Letter Spacing:** +0.5px to +1px
- **Usage:** Captions, timestamps, helper text

### Font Sizes

**Web/Digital:**
- H1 (Logo/Main Title): 28–42px
- H2 (Section Title): 20–28px
- H3 (Subsection): 16–20px
- Body: 14–16px
- Small (UI/Captions): 12–14px

### Do's and Don'ts

✅ **DO:**
- Use the system font stack
- Apply appropriate letter spacing for readability
- Use semibold (500) for hierarchy emphasis
- Keep line-height generous (1.5–1.6) for body text

❌ **DON'T:**
- Use decorative or script fonts
- Use overly rounded or childish fonts
- Use heavy italics for large text (reserve for emphasis)
- Use more than 2 font weights in the same context

## 7. Logo Usage Guidelines

### Approved Backgrounds

#### Light Backgrounds
- White (#FFFFFF)
- Light Gray (#FAFBF8)
- Light neutral colors
- **Use:** Light version of logo (default icon.svg)

#### Dark Backgrounds
- Dark Gray (#0F0F0F)
- Dark colors (charcoal, navy, etc.)
- Dark photos with adequate contrast
- **Use:** Dark version of logo (icon-dark.svg)

#### Complex Backgrounds
- Photography, patterns, gradients
- **Always use:** Monochrome version (icon-mono.svg) or a solid background shape
- Add a subtle background container (white or semi-transparent dark) if needed

### DO's: Correct Logo Usage

✅ **DO:**
- Maintain clear space around all sides
- Use the SVG or high-resolution PNG at appropriate sizes
- Keep aspect ratio 1:1 for the icon
- Use the provided color palette
- Apply the logo consistently across all touchpoints
- Ensure adequate contrast with backgrounds
- Use dark mode version on dark backgrounds

### DON'Ts: Logo Misuse

❌ **DON'T:**
- Distort or skew the logo (maintain perfect 1:1 aspect ratio for icon)
- Change the colors (use only brand palette)
- Add drop shadows or effects (keep it clean)
- Rotate the logo to make it look "dynamic"
- Use the light version on light backgrounds
- Use the dark version on light backgrounds
- Combine the icon with different wordmarks
- Outline or stroke the mark
- Add gradients or complex effects
- Use it at sizes below the minimum specified
- Change the line widths of the placement guides
- Add decorative elements around the logo

### Clear Space Examples

For a 40px icon mark:
- Clear space on all sides: **40px minimum**
- No other elements, text, or graphics within this zone
- Applies to horizontal/vertical/diagonal directions equally

## 8. Icon Usage (App Icons & Favicon)

### App Icon (iOS, Android, Desktop, Browser Extension)

**Format:** PNG, 512×512px minimum (for maximum flexibility)

**Safe Zone:** The icon is designed to fit safely within a circle (for iOS App Library)

**Rounded Corners:** Apply rounded corners per platform:
- **iOS:** System handles rounding (provide square PNG)
- **Android:** System handles rounding (provide square PNG)
- **Desktop:** Depends on platform (Windows: square; macOS: prefer square)
- **Web:** Depends on design; square is universal

**Use Files:**
- Light Mode: `icon-512x512.png`
- Dark Mode: `icon-dark-512x512.png`

### Favicon Usage

**Favicon Files Provided:**
- `favicon.svg` — Scalable favicon (modern browsers)
- `favicon.ico` — 32×32 ICO format (IE compatibility)
- `favicon-32x32.png` — Preferred PNG format
- `favicon-16x16.png` — Fallback small size

**Implementation (HTML):**
```html
<!-- Modern browsers (SVG + PNG) -->
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
<link rel="icon" type="image/png" href="/favicon-32x32.png">

<!-- iOS home screen -->
<link rel="apple-touch-icon" href="/favicon-192x192.png">

<!-- Legacy IE compatibility -->
<link rel="shortcut icon" href="/favicon.ico">
```

**Favicon Best Practices:**
- SVG version scales perfectly on any display
- PNG version ensures compatibility
- The icon remains recognizable at 16×16px
- Avoid gradients or complex details (they won't render at tiny sizes)

## 10. Dark Mode & Light Mode

### Light Mode (Default)
- **Logo Color:** #2D6E6E (Teal Calm)
- **Background:** #FAFBF8 or lighter
- **Text:** #1F1F1F (Dark)
- **File to Use:** `icon.svg`, `logo-primary.svg`, `logo-horizontal.svg`

### Dark Mode
- **Logo Color:** #E8F4F3 (Light version of teal)
- **Background:** #0F0F0F or darker
- **Text:** #FAFBF8 (Light)
- **File to Use:** `icon-dark.svg`

### Implementation Guide

**CSS Media Query Approach:**
```css
@media (prefers-color-scheme: light) {
  .logo { /* Use light version */ }
}

@media (prefers-color-scheme: dark) {
  .logo { /* Use dark version */ }
}
```

**HTML Picture Element Approach:**
```html
<picture>
  <source media="(prefers-color-scheme: dark)" srcset="icon-dark.svg">
  <img src="icon.svg" alt="Save It Somewhere">
</picture>
```

## 11. Monochrome & Single-Color Applications

### When to Use Monochrome
- Black and white printing
- Embossing or engraving
- Single-color technical applications
- High-contrast requirements
- Laser etching

### Monochrome Specifications
- **Color:** Pure Black (#000000) or Pure White (#FFFFFF)
- **Background:** Opposite color for contrast
- **File:** `icon-mono.svg` or `icon-mono-*.png`

### Usage Examples
- ✅ Black on white paper (print)
- ✅ White embossed on product
- ✅ Black laser-etched on acrylic
- ✅ Reversed out on packaging
- ❌ Gray monochrome (use color instead)
- ❌ Colored monochrome (use color version)

## 12. Logo Tests (Validation Checklist)

Before deploying the logo in any new context, validate it passes these tests:

### 1-Second Recognition Test
- ✅ Can someone identify it as Save It Somewhere in 1 second?
- ✅ Is it distinctive among competitor logos?

### 16px Favicon Test
- ✅ Is the icon still identifiable at 16×16px?
- ✅ Are the placement guides still visible?
- ✅ Is it legible in browser tabs?

### Black & White Test
- ✅ Does the monochrome version work without color?
- ✅ Is it recognizable in grayscale?

### App Icon Test
- ✅ Would users comfortably put this on their phone home screen?
- ✅ Does it look premium on app store listings?
- ✅ Is it visually distinctive among other app icons?

### Conversation Test
- ✅ Would users naturally say *"I saved it in Save It Somewhere"*?
- ✅ Does the brand feel trustworthy with their personal information?

### Emotional Test
- ✅ Does it communicate relief and calm?
- ✅ Does it feel like "somewhere safe"?
- ✅ Does it avoid looking overly technical or AI-driven?
